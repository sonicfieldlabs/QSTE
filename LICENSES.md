# Licensing map

QSTE uses file-category licensing rather than applying one license to every
source or research artifact.

| Material | License or status |
| --- | --- |
| Original source code, tests, and build configuration | MIT; see `LICENSE` |
| QSTE-owned ontology, specifications, architecture, plan, and original documentation | Creative Commons Attribution 4.0 International (`CC-BY-4.0`) |
| Research papers and submission artifacts | Excluded from the blanket licenses; rights remain with their authors and applicable publication agreements |
| Third-party fixtures, contracts, models, corpora, and tools | Their own licenses and permissions |

The CC BY 4.0 legal code is available from
<https://creativecommons.org/licenses/by/4.0/legalcode>. An authority or source
manifest may further restrict disclosure or redistribution for a particular
artifact. Repository presence never establishes permission for downstream use.
