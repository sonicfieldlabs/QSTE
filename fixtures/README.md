# Fixtures

`schema/0.3.0/` contains deterministic P2 conformance fixtures: minimal,
maximal, invalid-type, missing-required, withheld, forward-extension,
operation-envelope, typed-payload, bundle, and cross-record closure families.

These are simulated contract examples. They are not empirical observations,
scientific results, human reports, operational receipts, or evidence that a
later QSTE capability exists. A fixture demonstrates only the contract claim
named by its profile.
