# P6 task and DSQ conformance

This profile verifies `qste-paired-score-task/v0.1` and
`qste-dsq-assessment/v0.1` against the ontology's two-bound, closed-refinement,
negative-evidence, and append-only invalidation rules.

Passing this profile means the bounded reference assessor behaves as declared.
It does not establish that any real-world candidate is a DSQ, validate the
design-only Leonardo example, or supply cross-representation evidence.
