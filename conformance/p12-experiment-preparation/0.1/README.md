# P12a experiment-preparation conformance

This public profile specifies the runtime boundary for freezing an experiment
preparation packet and checking a synthetic, nonconfirmatory method pilot. The
fixtures demonstrate contract behavior only. They are not a research plan,
registered protocol, scientific pilot, result, or evidence for a QSTE claim.

The profile requires explicit rights, calibration scope, frozen parameters,
leakage checks, safety flags, immutable artifacts, and durable receipts. Human
collection, confirmatory execution, external engines and models, playback,
network access, and public research projection remain outside the capability.

Run `make experiment-preparation-contracts` to verify the profile and its
synthetic fixtures.
